Bills Receipt Creation

Create the warehouse receipt of a vendor bill in one click

Features

✅ Create Receipt button on posted vendor bills: creates and confirms the incoming picking.
✅ Receipts smart button on the bill, linked through a real relation (safe in multi-company databases).
✅ Receipt valued at the billed cost; bill lines moved to the stock input account (automated valuation).
✅ No duplicate receipts: the button is hidden once a receipt exists.
✅ Uses the receipt operation type and locations of the bill's company.

How to use

1. Create and post a vendor bill containing storable or consumable products.
2. Click Create Receipt.
3. Open the Receipts smart button and validate the receipt.
