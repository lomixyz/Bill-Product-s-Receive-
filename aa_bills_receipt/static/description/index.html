Bills Receipt Creation

Create the warehouse receipt of a vendor bill in one click — so your stock never falls behind your accounting.

How it works

Three steps — no wizard, no extra clicks.

1
Post the vendor bill
Once a vendor bill with storable or consumable lines is posted, a Create Receipt button appears on it — nothing to configure first.
2
Click “Create Receipt”
An incoming transfer is created and confirmed automatically, with the bill's own lines and valued at the billed cost.
3
Validate the receipt
Open it from the Receipts smart button on the bill and validate it like any other warehouse transfer.

Key features

🔢 One-click receipt creation
No wizard, no manual stock move — one button on the posted bill creates and confirms the whole transfer.
🔗 Real relation to the bill
Receipts are linked to their bill through an actual field, not by matching the reference — safe in multi-company databases.
🚫 No duplicate receipts
The button disappears automatically once a receipt already exists for the bill.
🏢 Multi-company safe
Uses the receipt operation type and locations of the bill's own company, never another one's.
💰 Valued at the billed cost
The receipt is priced straight from the bill's own line prices, using Odoo 20's own per-location valuation accounts.
⚙️ No setup required
Works out of the box on any posted vendor bill with storable or consumable lines — nothing to configure.

⚙️ How to use

  1. Install the module (depends on Accounting and Inventory, pulled in automatically).
  2. Create and post a vendor bill containing storable or consumable products.
  3. Click Create Receipt in the bill's header.
  4. Open the Receipts smart button and validate the transfer — done.

ℹ️ Odoo 20 valuation note

Odoo 20 values a receipt directly from the stock move, through the valuation accounts set on the source and destination locations (Inventory > Configuration > Locations) — the old per-category "Stock Input Account" from earlier Odoo versions no longer exists. This module never touches the bill line's account; make sure the relevant locations have a valuation account configured.
